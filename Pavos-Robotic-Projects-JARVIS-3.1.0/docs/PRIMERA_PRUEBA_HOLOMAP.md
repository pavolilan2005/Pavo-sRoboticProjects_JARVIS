# Primera prueba HOLOMAP

1. Ejecuta `INSTALAR_JARVIS.bat` para instalar `PyQt6-WebEngine`.
2. Inicia JARVIS y pulsa `HOLOMAP`.
3. Confirma que el globo carga y permite arrastrar/zoom.
4. Busca `Pirámides de Giza`.
5. Selecciona un resultado y comprueba el vuelo de cámara.
6. Haz clic en el planeta y revisa las coordenadas.
7. Guarda el punto con un nombre.
8. Fija un punto como ubicación principal y prueba el botón `CASA`.
9. Activa y desactiva `ÓRBITA` y `VISTA: CALLES/HOLO`.
10. Prueba por voz: `Jarvis, llévame al CERN`.

Si el panel indica que CesiumJS no pudo cargarse, revisa conexión a Internet o firewall. El resto de JARVIS debe continuar funcionando.
