# PRP JARVIS 3.2.2 — HOLOMAP Tiles Fix

## Corrección

- Eliminado el uso directo de `tile.openstreetmap.org`.
- HOLOMAP usa ArcGIS World Imagery como vista holográfica remota.
- El modo calles usa ArcGIS World Street Map.
- Se añadió Natural Earth II como respaldo automático.
- Si el proveedor remoto falla, el globo sigue siendo navegable.
- Se conservaron búsqueda, marcadores, vuelo, órbita y comandos de voz.
- No se modificaron Gemini, audio, Spotify, OBS ni ESP32.
